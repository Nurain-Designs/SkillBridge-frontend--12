# SkillBridge UI Guidelines

* Use modern dashboard UI
* Use responsive layout
* Use dark blue and white color theme
* Use clean cards and analytics charts
* Keep UI minimal and professional
* Use sidebar navigation
* Add resume upload section
* Add skill gap analysis charts
* Add learning roadmap timeline
* Use rounded corners and soft shadows
* Use modern fonts like Inter or Poppins
* Optimize for desktop and mobile screens
* Keep spacing clean and readable
* Use AI/analytics style components
