# 🚀 SkillBridge: Agentic AI Career Advisor & Skill Gap Analyser

![SkillBridge AI Career Advisor](public/ai-career_advisor.png)

**SkillBridge** is an intelligent, autonomous career development and skill gap analysis platform designed to democratize access to personalized, data-driven professional guidance. 

Developed during an internship at **MJ Smart Solutions**, SkillBridge combines a modern, premium UI with a robust Agentic AI backend. It allows users to upload their resumes, input desired job descriptions, and receive a customized **4-week learning roadmap** generated by a local Large Language Model.

## ✨ Features

- **📄 Intelligent Resume Parsing:** Ingests and processes unstructured data from PDF resumes and free-text job descriptions.
- **🧠 Semantic Skill Extraction:** Utilizes Natural Language Processing (`spaCy`) to understand and extract both hard and soft skills aligned with taxonomies like O*NET.
- **🔍 Automated Gap Computation:** Cross-references candidate skills against job requirements to pinpoint exact missing proficiencies.
- **📚 Contextual Resource Retrieval (RAG):** Uses a Retrieval-Augmented Generation (RAG) architecture with a local **FAISS** vector database to match skill gaps with high-quality educational resources.
- **🗺️ Dynamic Roadmap Generation:** Generates a personalized 4-week learning roadmap synthesizing missing skills and recommended courses into a structured study plan.
- **🔒 Privacy-First Architecture:** Runs AI inference locally using **Ollama** and **Llama 3.2**, ensuring sensitive resume data is never transmitted to third-party APIs.
- **🎨 Premium UI/UX:** Built with React, Vite, Tailwind CSS, and Framer Motion, featuring a highly engaging dark-themed 3D glassmorphism aesthetic.

## 🛠️ Tech Stack

### Frontend
- **Framework:** React 18 & Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Components:** Radix UI / shadcn/ui

### Backend & AI
- **Language:** Python 3.9+
- **Interface:** Streamlit / API Server
- **LLM Orchestration:** LangChain
- **Local AI:** Ollama (running Llama 3.2)
- **NLP:** spaCy (`en_core_web_sm`)
- **Vector Database:** FAISS
- **PDF Processing:** PyPDF2
